# Product Requirement Document (PRD)

# Website Portofolio Personal Minimalist Modern

## 1. Overview

### Nama Produk

Personal Portfolio Website

### Deskripsi

Website portofolio personal yang menampilkan identitas, kemampuan,
pengalaman, serta hasil karya dalam satu halaman yang modern, minimalis,
dan responsif. Website menggunakan konsep clean design dengan warna yang
tidak mencolok, memberikan kesan profesional, elegan, dan kekinian.

Website memiliki fitur dark mode dan light mode sehingga pengguna dapat
memilih tampilan sesuai preferensi.

------------------------------------------------------------------------

# 2. Tujuan Website

Website ini bertujuan untuk:

-   Menampilkan profil diri secara profesional.
-   Memperkenalkan skill dan kemampuan yang dimiliki.
-   Menampilkan project yang pernah dibuat.
-   Menjadi media personal branding.
-   Memberikan informasi kontak dan sosial media agar mudah dihubungi.

------------------------------------------------------------------------

# 3. Target User

-   Recruiter atau perusahaan.
-   Client yang membutuhkan jasa.
-   Komunitas teknologi.
-   Pengunjung yang ingin mengetahui profil dan karya.

------------------------------------------------------------------------

# 4. Konsep Design

## Style Design

Tema utama:

-   Minimalist
-   Modern
-   Clean
-   Professional
-   Futuristic sederhana

## Color Theme

Light Mode: - Background: putih atau abu terang. - Text: hitam. -
Secondary: abu.

Dark Mode: - Background: hitam soft. - Text: putih. - Secondary: abu
terang.

Accent menggunakan warna lembut seperti: - Soft blue - Soft purple -
Soft green

## Design Principle

-   Banyak whitespace.
-   Typography sebagai fokus utama.
-   Animasi smooth dan sederhana.
-   Tidak menggunakan warna terlalu mencolok.

------------------------------------------------------------------------

# 5. Struktur Website

Website menggunakan konsep single page.

    Navbar
     |
    About / Hero Section
     |
    Skill Section
     |
    Project Section
     |
    Social Media & Contact
     |
    Footer

------------------------------------------------------------------------

# 6. Functional Requirement

## Navbar

Fungsi: Memberikan navigasi antar section.

Isi: - Logo/Nama - About - Skills - Projects - Contact - Theme Toggle

Requirement: - Sticky navbar. - Smooth scrolling. - Responsive mobile.

------------------------------------------------------------------------

## About / Hero Section

Menampilkan informasi utama.

Isi: - Foto profile. - Nama lengkap. - Role pekerjaan. - Deskripsi
singkat. - Tombol Download CV. - Tombol Contact.

Contoh:

    Hello, I'm

    Nama User

    Frontend Developer

    Membuat website modern dengan
    fokus pada performa dan pengalaman pengguna.
